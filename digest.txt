## 4. KEY ARCHITECTURAL DECISIONS

### 4.1 URL Scheme (TripAdvisor-style)

**Geo pages (places):**
/Tourism-g{geoId}-{slug} → overview
/Hotels-g{geoId}-{slug} → hotels only
/Treks-g{geoId}-{slug} → treks only
/Transports-g{geoId}-{slug} → transport only
/Guides-g{geoId}-{slug} → guides only
/Permits-g{geoId}-{slug} → permits only

text

**POI pages (things):**
/<Category>_Review-g{geoId}-d{poiId}-{slug}

text

Examples:
- `/Trek_Review-g97710301-d100001-everest-base-camp-trek`
- `/Hotel_Review-g97740501-d200002-yak-yeti-pokhara`

**Both handled by ONE catch-all route:** `app/[slug]/page.tsx`

**REGEX PARSING (critical):**
- POI: `^([A-Za-z]+)_Review-g(\d+)-d(\d+)-(.+)$`
- GEO: `^([A-Za-z]+)-g(\d+)-(.+)$`

**DO NOT create separate `[geo]` and `[poi]` folders.** Next.js forbids two dynamic folders with different names at the same level.

### 4.2 Geo ID Scheme (Government-backed)

Based on Nepal's official district codes (Central Bureau of Statistics):
977 Nepal (country code)
9771-9777 Provinces (1-7)
977 + gov_district Districts (e.g., 977306 = Kathmandu, gov code 306)
977 + district + XX Cities (e.g., 97730601 = Kathmandu city)

text

**Rules:**
- Root = `977` (Nepal dialing code)
- District = `977` + CBS 3-digit code
- City = district ID + 2-digit sequence (01-99)
- Max ID length: 8 digits

**NO `place` level in Geo.** Places (Thamel, EBC, Phewa Lake) are POIs with category `place`.

### 4.3 POI ID Scheme (Category blocks)
100000-199999 Trek
200000-299999 Hotel
300000-399999 Restaurant
400000-499999 Transport
500000-599999 Guide
600000-699999 Permit
700000-799999 Place

text

6-digit IDs. First digit = category. Auto-increment within block (but seeded with explicit IDs).

### 4.4 Auth Architecture

- **Auth.js v5** with Prisma adapter
- **JWT sessions** (not DB sessions)
- **Google OAuth** with `allowDangerousEmailAccountLinking: true` (auto-links if email matches)
- **Credentials (email/password)** for email signups
- **Session callback** adds `id` and `role` to session
- **JWT callback** fetches fresh `role` and `image` from DB on sign-in
- **`signIn` callback** forces `user.image = profile.picture` for Google users

**Google config in `auth.ts`:**
```ts
Google({
  allowDangerousEmailAccountLinking: true,
  authorization: {
    params: {
      scope: "openid email profile",
      prompt: "consent",
    },
  },
}),

6. KNOWN ISSUES / BUGS
Issue 1 — Email/Password Login on Google-Only Account
Symptom: User signs up with Google. Later tries email/password login. Fails with "Invalid email or password."

Root cause: passwordHash is NULL for Google-only users. The authorize() function returns null when !user.passwordHash.

Status: This is expected behavior, not a bug. But the error message is misleading.

Recommended fix (not yet applied):

In auth.ts authorize(): if user.passwordHash is null, throw Error("oauth_only_account")

In login/page.tsx: catch that error and show "This account was created with Google. Use 'Continue with Google' instead."

Long-term: Build a "set password" feature in /profile for OAuth-only users.

Issue 2 — Prisma Duplicate poiUrl Functions
File: lib/geo.ts

Symptom: Two poiUrl function definitions exist — one uses /Poi_Review-..., one uses /${poiCategoryKey(category)}_Review-....

Status: Needs verification. If both exist, TypeScript will error. Only ONE should exist — the category-specific version.

Recommended fix: Delete the old /Poi_Review-... version. Keep poiCategoryKey + new poiUrl.

However: Old /Poi_Review-... URLs still resolve (regex accepts any _Review prefix) but don't redirect to canonical. Optional: add category check in renderPoiPage redirect.

Issue 3 — Google OAuth credentials leaked in chat
Status: RESOLVED. User rotated Google Client Secret. New credentials in .env, NOT in git.

Ongoing requirement: NEVER paste secrets in chat. Rotate immediately if leaked.

Issue 4 — Email Signup Without Google (Potential)
Status: Not tested. If a user signs up with email/password first, then tries Google with same email, auto-linking should work (because allowDangerousEmailAccountLinking: true). But not verified.

9.1 Client vs Server Components
Server components by default — no "use client" unless needed

"use client" required when: using useState, useEffect, useSession, signIn, signOut, event handlers, useRouter from next/navigation

Server components can call auth() — prefer over useSession() when possible

Server components can query Prisma directly — no need for API route just for server-side fetch

9.2 Tailwind Conventions
Sky-600 is the primary accent color (buttons, links)

Slate is the neutral palette (text, borders)

Rounded corners: rounded-xl (inputs/buttons), rounded-3xl (cards)

Padding: p-6 for cards, px-4 py-2.5 for inputs

Font weights: font-extrabold for headings, font-bold for buttons/labels

Focus rings: focus:border-sky-600 focus:ring-2 focus:ring-sky-100

9.3 Next.js 16 Notes
params is a Promise — always await params before accessing

searchParams is a Promise — always await searchParams

cookies(), headers(), draftMode() are Promises — always await

Route names can't mix literal text with brackets at same segment level — use single [slug] with regex parsing

9.4 Prisma Conventions
Always use prisma singleton from @/lib/prisma

select specific fields when possible (avoid *)

Use include for relations when you need the nested object

Use groupBy for counts

Always await queries in server components

9.5 API Route Conventions
POST returns { error: string } with 4xx/5xx on failure

POST returns { <resource>: object } with 201 on success

GET returns { <resource>s: [] } or { <resource>: object }

Always check auth with await auth() for write endpoints

Return early for validation errors

Log unexpected errors with console.error

9.6 Client-Side Form Conventions
useState for all fields

loading state for submit button

error string state for validation errors

success state (optional) with auto-hide after 3s

On success: router.refresh() to re-fetch server data

On navigation success: router.push(callbackUrl || "/")

9.7 TypeScript Conventions
Define inline types where used

Use as casting sparingly (only when Auth.js types are incomplete)

Define reusable types in types/ folder (e.g., next-auth.d.ts)

Prefer type over interface for data shapes

Use Promise<T> for async function params in Next.js 16

import NextAuth from "next-auth";
import Credentials from "next-auth/providers/credentials";
import { PrismaAdapter } from "@auth/prisma-adapter";
import bcrypt from "bcryptjs";
import { prisma } from "@/lib/prisma";
import Google from "next-auth/providers/google";

export const { handlers, auth, signIn, signOut } = NextAuth({
  adapter: PrismaAdapter(prisma),
  session: { strategy: "jwt" },
  pages: {
    signIn: "/login",
  },
  providers: [
    Google({
      allowDangerousEmailAccountLinking: true,
      authorization: {
        params: {
          scope: "openid email profile",
          prompt: "consent",
        },
      },
    }),
    Credentials({
      name: "credentials",
      credentials: {
        email: { label: "Email", type: "email" },
        password: { label: "Password", type: "password" },
      },
      async authorize(credentials) {
        if (!credentials?.email || !credentials?.password) return null;

        const user = await prisma.user.findUnique({
          where: { email: (credentials.email as string).toLowerCase() },
        });
        if (!user || !user.passwordHash) return null;

        const valid = await bcrypt.compare(
          credentials.password as string,
          user.passwordHash
        );
        if (!valid) return null;

        return {
          id: user.id,
          email: user.email,
          name: user.name,
          image: user.image,
        };
      },
    }),
  ],
  callbacks: {
    async signIn({ user, account, profile }) {
      // Ensure Google profile picture is saved
      if (account?.provider === "google" && profile?.picture) {
        user.image = profile.picture as string;
      }
      return true;
    },

    async jwt({ token, user }) {
      if (user) {
        token.id = user.id;

        const dbUser = await prisma.user.findUnique({
          where: { id: user.id as string },
          select: { role: true, image: true },
        });

        token.role = dbUser?.role ?? "traveler";
        token.picture = user.image ?? dbUser?.image ?? null;
      }
      return token;
    },

    async session({ session, token }) {
      if (token && session.user) {
        session.user.id = token.id as string;
        (session.user as any).role = token.role;
        if (token.picture) {
          session.user.image = token.picture as string;
        }
      }
      return session;
    },
  },
});

async function renderGeoPage(match: RegExpMatchArray) {
  const [, sectionKey, geoIdStr, slug] = match;
  const geoIdNum = Number(geoIdStr);
  if (!Number.isFinite(geoIdNum)) notFound();

  const sectionConfig = getSectionByKey(sectionKey);
  if (!sectionConfig) notFound();

  const geo = await prisma.geo.findUnique({
    where: { geoId: geoIdNum },
    select: {
      geoId: true,
      parentId: true,
      name: true,
      type: true,
      slug: true,
    },
  });
  if (!geo) notFound();

  if (geo.slug !== slug) {
    redirect(`/${sectionConfig.key}-g${geo.geoId}-${geo.slug}`);
  }

  const grouped = await prisma.poi.groupBy({
    by: ["category"],
    where: { geoId: geoIdNum },
    _count: { _all: true },
  });
  const counts: Record<string, number> = {};
  for (const g of grouped) {
    counts[g.category] = g._count._all;
  }

  const pois = await prisma.poi.findMany({
    where: {
      geoId: geoIdNum,
      ...(sectionConfig.category ? { category: sectionConfig.category } : {}),
    },
    include: { geo: true },
    orderBy: [{ rating: "desc" }, { poiId: "asc" }],
  });

  const breadcrumb = await buildBreadcrumb(geo as GeoRow);

  return (
    <div className="max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 py-6 w-full">

import { NextResponse } from "next/server";
import { prisma } from "@/lib/prisma";

export async function GET(req: Request) {
  const { searchParams } = new URL(req.url);
  const q = searchParams.get("q")?.trim() ?? "";

  if (q.length < 2) {
    return NextResponse.json({ results: [] });
  }

  const likeTerm = `%${q}%`;

  const rows = await prisma.$queryRaw<
    Array<{
      id: number;
      name: string;
      description: string | null;
      slug: string;
      subcategorySlug: string | null;
      subcategoryName: string | null;
      categorySlug: string | null;
      categoryName: string | null;
    }>
  >`
    SELECT
      p.id,
      p.name,
      p.description,
      p.slug,
      s.slug AS subcategorySlug,
      s.name AS subcategoryName,
      c.slug AS categorySlug,
      c.name AS categoryName
    FROM Permit p
    LEFT JOIN Permit s ON p.parentId = s.id
    LEFT JOIN Permit c ON s.parentId = c.id
    WHERE p.type = 'permit'
      AND (
        p.name LIKE ${likeTerm}
        OR JSON_EXTRACT(p.aliases, '$') LIKE ${likeTerm}
        OR p.description LIKE ${likeTerm}
      )
    ORDER BY p.name ASC
    LIMIT 10
  `;

  const results = rows.map((row) => ({
    id: row.id,
    name: row.name,
    description: row.description ?? "",
    categoryName: row.categoryName ?? "",
    categorySlug: row.categorySlug ?? "",
    subcategoryName: row.subcategoryName ?? "",
    subcategorySlug: row.subcategorySlug ?? "",
    url:
      row.categorySlug && row.subcategorySlug
        ? `/Nepal-Permits/${row.categorySlug}/${row.subcategorySlug}/${row.slug}`
        : "#",
  }));

  return NextResponse.json({ results });
}

import { NextResponse } from "next/server";
import { auth } from "@/auth";
import { prisma } from "@/lib/prisma";

export async function PATCH(req: Request) {
  // 1. Auth check
  const session = await auth();
  if (!session?.user?.id) {
    return NextResponse.json({ error: "Not logged in" }, { status: 401 });
  }

  // 2. Parse body
  const body = await req.json();
  const { name, email } = body;

  // 3. Validate
  if (name !== undefined) {
    if (typeof name !== "string" || name.trim().length < 1) {
      return NextResponse.json(
        { error: "Name must be at least 1 character" },
        { status: 400 }
      );
    }
    if (name.trim().length > 100) {
      return NextResponse.json(
        { error: "Name must be under 100 characters" },
        { status: 400 }
      );
    }
  }

  if (email !== undefined) {
    if (typeof email !== "string" || !email.includes("@")) {
      return NextResponse.json(
        { error: "Invalid email address" },
        { status: 400 }
      );
    }

    // Check if email is already taken by another user
    const normalizedEmail = email.toLowerCase().trim();
    const existing = await prisma.user.findUnique({
      where: { email: normalizedEmail },
    });
    if (existing && existing.id !== session.user.id) {
      return NextResponse.json(
        { error: "Email is already in use" },
        { status: 409 }
      );
    }
  }

  // 4. Build update data
  const data: { name?: string; email?: string } = {};
  if (name !== undefined) data.name = name.trim();
  if (email !== undefined) data.email = email.toLowerCase().trim();

  if (Object.keys(data).length === 0) {
    return NextResponse.json({ error: "Nothing to update" }, { status: 400 });
  }

  // 5. Update
  const updated = await prisma.user.update({
    where: { id: session.user.id },
    data,
    select: {
      id: true,
      name: true,
      email: true,
    },
  });

  return NextResponse.json({ user: updated });
}

  }

    );

      { error: "Review text must be at least 10 characters" },

    );
  }

  if (text.length > 2000) {
    return NextResponse.json(
      { error: "Review text must be under 2000 characters" },
      { status: 400 }
    );
  }

    where: { poiId },
    select: { poiId: true },
  });
  if (!poi) {
    return NextResponse.json({ error: "POI not found" }, { status: 404 });
  }

  const existing = await prisma.review.findUnique({
    where: {
      userId_poiId: {
        userId: session.user.id,
        poiId,
      },
    },
  });
  if (existing) {
    return NextResponse.json(
      { error: "You have already reviewed this place" },
      { status: 409 }
    );
  }

  const review = await prisma.review.create({
    data: {
      userId: session.user.id,
      poiId,
      rating,
      text: text.trim(),
    },
    include: {
      user: {
        select: { id: true, name: true, image: true },
      },
    },
  });

  const agg = await prisma.review.aggregate({
    where: { poiId },
    _avg: { rating: true },
  });

  await prisma.poi.update({
    where: { poiId },
    data: { rating: agg._avg.rating ?? null },
  });

  return NextResponse.json({ review }, { status: 201 });
}

import { prisma } from "@/lib/prisma";

export async function POST(req: Request) {
  try {
    const body = await req.json();
    const { name, email, password } = body;

    if (!email || !password) {
      return NextResponse.json(
        { error: "Email and password are required" },
        { status: 400 }
      );
    }

    if (typeof password !== "string" || password.length < 8) {
      return NextResponse.json(
        { error: "Password must be at least 8 characters" },
        { status: 400 }
      );
    }

    const normalizedEmail = String(email).toLowerCase().trim();

    const existing = await prisma.user.findUnique({
      where: { email: normalizedEmail },
    });

    if (existing) {
      return NextResponse.json(

    const passwordHash = await bcrypt.hash(password, 12);

    const user = await prisma.user.create({
      data: {
        name: name || null,
        email: normalizedEmail,
        passwordHash,
      },
      select: { id: true, email: true, name: true, role: true },
    });

    return NextResponse.json({ user }, { status: 201 });
  } catch (err) {
    console.error("Signup error:", err);
    return NextResponse.json(
      { error: "Something went wrong" },
      { status: 500 }
    );
  }
}

import { prisma } from "@/lib/prisma";

export default async function PoiCatalog({
  category,
  title,
  description,
  q,
}: {
  category: string;
  title: string;
  description: string;
  q?: string;
}) {
  const query = q?.trim() ?? "";

    where: {
      category,
      ...(query.length >= 2 ? { name: { contains: query } } : {}),

    orderBy: [{ rating: "desc" }, { poiId: "asc" }],

        <p className="text-xs text-slate-400 mt-1">

        <div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6 mt-8">

"use client";

import { useState, useEffect, useRef } from "react";
import Link from "next/link";
import { Search, MapPin, Compass, Hotel, Bus, User, FileText, Camera, Utensils } from "lucide-react";

type Result = {
  type: "geo" | "poi";
  id: number;
  name: string;
  type_detail: string;
  slug: string;
  url: string;
  subtitle: string;
};

// Icon per category
const categoryIcon = (detail: string) => {
  switch (detail) {
    case "country":
    case "province":
    case "district":
    case "city":
      return MapPin;
    case "trek":
      return Compass;
    case "hotel":
      return Hotel;
    case "restaurant":
      return Utensils;
    case "transport":
      return Bus;
    case "guide":
      return User;
    case "permit":
      return FileText;
    case "place":
      return Camera;
    default:
      return Search;
  }
};

export default function SearchBox() {
  const [q, setQ] = useState("");
  const [results, setResults] = useState<Result[]>([]);
  const [open, setOpen] = useState(false);
  const [loading, setLoading] = useState(false);
  const wrapperRef = useRef<HTMLDivElement>(null);

  // Fetch results whenever q changes (debounced)
  useEffect(() => {
    if (q.trim().length < 2) {
      setResults([]);
      setOpen(false);
      return;
    }

    setLoading(true);
    const controller = new AbortController();
    const timer = setTimeout(async () => {
      try {
        const res = await fetch(`/api/search?q=${encodeURIComponent(q.trim())}`, {
          signal: controller.signal,
        });
        const data = await res.json();
        setResults(data.results ?? []);
        setOpen(true);
      } catch (err: any) {
        if (err.name !== "AbortError") console.error("Search error:", err);
      } finally {
        setLoading(false);
      }
    }, 200); // 200ms debounce

    return () => {
      clearTimeout(timer);
      controller.abort();
    };
  }, [q]);

  // Close dropdown when clicking outside
  useEffect(() => {
    function handleClickOutside(e: MouseEvent) {
      if (wrapperRef.current && !wrapperRef.current.contains(e.target as Node)) {
        setOpen(false);
      }
    }
    document.addEventListener("mousedown", handleClickOutside);
    return () => document.removeEventListener("mousedown", handleClickOutside);
  }, []);

  return (
    <div ref={wrapperRef} className="relative w-full max-w-2xl mx-auto">
      {/* Input */}
      <div className="flex items-center bg-white rounded-full shadow-lg px-4 py-3">
        <Search className="w-4 h-4 text-slate-400 shrink-0" />
        <input
          type="text"
          value={q}
          onChange={(e) => setQ(e.target.value)}
          onFocus={() => results.length > 0 && setOpen(true)}
          placeholder="Search destinations, treks, hotels..."
          className="w-full bg-transparent text-sm font-medium text-slate-800 placeholder:text-slate-400 focus:outline-none px-3"
        />
        {loading && (
          <div className="w-4 h-4 border-2 border-sky-600 border-t-transparent rounded-full animate-spin" />
        )}
      </div>

      {/* Dropdown */}
      {open && results.length > 0 && (
        <ul className="absolute top-full left-0 right-0 mt-2 bg-white rounded-2xl shadow-2xl border border-slate-200 overflow-hidden z-50 max-h-[400px] overflow-y-auto">
          {results.map((r) => {
            const Icon = categoryIcon(r.type_detail);
            return (
              <li key={`${r.type}-${r.id}`}>
                <Link
                  href={r.url}
                  onClick={() => {
                    setOpen(false);
                    setQ("");
                  }}
                  className="flex items-center gap-3 px-4 py-3 hover:bg-sky-50 transition-colors border-b border-slate-100 last:border-b-0"
                >
                  <div className="w-8 h-8 rounded-full bg-sky-100 flex items-center justify-center shrink-0">
                    <Icon className="w-4 h-4 text-sky-600" />
                  </div>
                  <div className="flex-1 min-w-0">
                    <div className="font-bold text-sm text-slate-900 truncate">
                      {r.name}
                    </div>
                    <div className="text-xs text-slate-500 truncate capitalize">
                      {r.subtitle}
                    </div>
                  </div>
                  <span className="text-xs font-bold text-sky-600 shrink-0">
                    View →
                  </span>
                </Link>
              </li>
            );
          })}
        </ul>
      )}

      {/* No results */}
      {open && q.trim().length >= 2 && results.length === 0 && !loading && (
        <div className="absolute top-full left-0 right-0 mt-2 bg-white rounded-2xl shadow-2xl border border-slate-200 p-4 text-center text-sm text-slate-500 z-50">
          No results for &quot;{q}&quot;
        </div>
      )}
    </div>
  );
}

import { useEffect } from "react";
import { X } from "lucide-react";

export type LightboxData = {
  name: string;
  subtitle: string;
  imageSrc?: string;
  fee: string;
  issuer: string;
  format: string;
  where: string;
  number: string;
  color: "blue" | "green" | "orange" | "red" | "purple";
};

const COLOR_MAP = {
  blue: "from-blue-50 to-blue-100",
  green: "from-green-50 to-green-100",
  orange: "from-orange-50 to-orange-100",
  red: "from-red-50 to-red-100",
  purple: "from-purple-50 to-purple-100",
};

export default function PermitLightbox({
  data,
  onClose,
}: {
  data: LightboxData;
  onClose: () => void;
}) {
  // Close on Escape key
  useEffect(() => {
    function handleEscape(e: KeyboardEvent) {
      if (e.key === "Escape") onClose();
    }
    document.addEventListener("keydown", handleEscape);

    // Prevent body scroll while lightbox is open
    const originalOverflow = document.body.style.overflow;
    document.body.style.overflow = "hidden";

    return () => {
      document.removeEventListener("keydown", handleEscape);
      document.body.style.overflow = originalOverflow;
    };
  }, [onClose]);

  return (
    <div
      className="fixed inset-0 z-[100] bg-black/80 backdrop-blur-sm flex items-center justify-center p-4 sm:p-8"
      onClick={onClose}
    >
      {/* Modal content — stop propagation so clicks inside don't close */}
      <div
        className="relative bg-white rounded-3xl max-w-4xl w-full max-h-[90vh] overflow-auto shadow-2xl"
        onClick={(e) => e.stopPropagation()}
      >
        {/* Close button */}
        <button
          onClick={onClose}
          className="absolute top-4 right-4 z-10 w-10 h-10 rounded-full bg-white/90 hover:bg-white shadow-lg flex items-center justify-center transition-colors"
          aria-label="Close"
        >
          <X className="w-5 h-5 text-slate-700" />

type SearchResult = {

  name: string;
  description: string;
  categoryName: string;
  categorySlug: string;
  subcategoryName: string;
  subcategorySlug: string;
  url: string;

type PopularPermit = {
  id: number;
  name: string;
  slug: string;
  parent: {
    slug: string;
    name: string;
    parent: {
      slug: string;
      name: string;
    } | null;
  } | null;
};

const CATEGORY_ICONS: Record<string, any> = {
  entry: Globe,
  trekking: Mountain,
  climbing: Mountain,
  special: Lock,
};

export default function PermitSearch({
  popularPermits,
}: {
  popularPermits: PopularPermit[];
}) {
  const [query, setQuery] = useState("");
  const [results, setResults] = useState<SearchResult[]>([]);
  const [focused, setFocused] = useState(false);
  const [loading, setLoading] = useState(false);
  const wrapperRef = useRef<HTMLDivElement>(null);
  const inputRef = useRef<HTMLInputElement>(null);

  // Fetch results when query changes
  useEffect(() => {
    if (query.trim().length < 2) {
      setResults([]);
      return;
    }

    setLoading(true);
    const controller = new AbortController();
    const timer = setTimeout(async () => {
      try {
        const res = await fetch(
          `/api/permits/search?q=${encodeURIComponent(query.trim())}`,
          { signal: controller.signal }
        );
        const data = await res.json();
        setResults(data.results ?? []);
      } catch (err: any) {
        if (err.name !== "AbortError") console.error("Search error:", err);
      } finally {
        setLoading(false);
      }
    }, 200);

    return () => {
      clearTimeout(timer);
      controller.abort();
    };
  }, [query]);

  // Close on outside click
  useEffect(() => {
    function handleClickOutside(e: MouseEvent) {
      if (
        wrapperRef.current &&
        !wrapperRef.current.contains(e.target as Node)
      ) {
        setFocused(false);
      }
    }
    document.addEventListener("mousedown", handleClickOutside);
    return () => document.removeEventListener("mousedown", handleClickOutside);
  }, []);

  // Close on Escape
  useEffect(() => {
    function handleKeyDown(e: KeyboardEvent) {
      if (e.key === "Escape") {
        setFocused(false);
        inputRef.current?.blur();
      }
    }
    document.addEventListener("keydown", handleKeyDown);
    return () => document.removeEventListener("keydown", handleKeyDown);
  }, []);

  function closeAndClear() {
    setFocused(false);
    setQuery("");
    setResults([]);
  }

  const showRecommendations = query.trim().length < 2;
  const hasResults = results.length > 0;

  return (
    <>
      {/* Backdrop */}
      {focused && (
        <div
          className="fixed inset-0 bg-black/40 z-30"
          onClick={() => setFocused(false)}
        />
      )}

      {/* Search container */}
      <div ref={wrapperRef} className="relative z-40">
        {/* Input bar */}
        <div className="flex items-center bg-white rounded-full shadow-lg border border-slate-200 px-4 py-3">
          <Search className="w-4 h-4 text-slate-400 shrink-0" />
          <input
            ref={inputRef}
            type="text"
            value={query}
            onChange={(e) => setQuery(e.target.value)}
            onFocus={() => setFocused(true)}
            placeholder="Search permits: TIMS, EBC Permit, Drone..."
            className="w-full bg-transparent text-sm font-medium text-slate-800 placeholder:text-slate-400 focus:outline-none px-3"
          />
          {loading && (
            <div className="w-4 h-4 border-2 border-sky-600 border-t-transparent rounded-full animate-spin shrink-0" />
          )}
          {query && !loading && (
            <button
              onClick={() => setQuery("")}
              className="text-slate-400 hover:text-slate-700 shrink-0"
            >
              <X className="w-4 h-4" />
            </button>
          )}
        </div>

        {/* Dropdown — only when focused */}
        {focused && (
          <div className="absolute top-full left-0 right-0 mt-2 bg-white rounded-2xl shadow-2xl border border-slate-200 overflow-hidden max-h-[70vh] overflow-y-auto">
            {/* STATE: recommendations (empty query) */}
            {showRecommendations && (
              <>
                {/* Popular permits */}
                {popularPermits.length > 0 && (
                  <div className="p-4 border-b border-slate-100">
                    <h3 className="text-[10px] font-black uppercase tracking-widest text-slate-400 mb-3">
                      Popular permits
                    </h3>
                    <ul className="space-y-1">
                      {popularPermits.map((p) => {
                        if (!p.parent || !p.parent.parent) return null;

                        return (
                          <li key={p.id}>
                            <Link
                              href={`/Nepal-Permits/${p.parent.parent.slug}/${p.parent.slug}/${p.slug}`}
                              onClick={closeAndClear}
                              className="flex items-center gap-3 px-3 py-2.5 rounded-lg hover:bg-sky-50 transition-colors group"
                            >
                              <FileText className="w-4 h-4 text-sky-600 shrink-0" />
                              <div className="flex-1 min-w-0">
                                <div className="font-bold text-sm text-slate-900 truncate">
                                  {p.name}
                                </div>
                                <div className="text-xs text-slate-500 truncate">
                                  {p.parent.parent.name} · {p.parent.name}
                                </div>
                              </div>
                              <ChevronRight className="w-4 h-4 text-slate-300 group-hover:text-sky-600 shrink-0" />
                            </Link>
                          </li>
                        );
                      })}
                    </ul>
                  </div>
                )}

                {/* Browse by category */}
                <div className="p-4">
                  <h3 className="text-[10px] font-black uppercase tracking-widest text-slate-400 mb-3">
                    Browse by category
                  </h3>
                  <div className="grid grid-cols-2 gap-2">
                    {[

"use client";

export default function ProfileForm({
  initialName,
  initialEmail,
}: {
  initialName: string;
  initialEmail: string;
}) {
  const router = useRouter();
  const [name, setName] = useState(initialName);
  const [email, setEmail] = useState(initialEmail);
  const [saving, setSaving] = useState(false);
  const [error, setError] = useState("");
  const [success, setSuccess] = useState(false);

  async function handleSubmit(e: React.FormEvent) {
    e.preventDefault();
    setError("");
    setSuccess(false);

    // No changes?
    if (name === initialName && email === initialEmail) {
      setError("No changes to save");
      return;
    }

    setSaving(true);

      method: "PATCH",
      headers: { "Content-Type": "application/json" },

    });

    setSaving(false);

    const data = await res.json();

    if (!res.ok) {
      setError(data.error || "Failed to save");
      return;
    }

    setSuccess(true);
    router.refresh();

    // Hide success after 3s
    setTimeout(() => setSuccess(false), 3000);
  }

  return (
    <form

export default function WishlistButton({
  poiId,
  size = "md",

  poiId: number;
  size?: "sm" | "md" | "lg";
}) {
  const { status } = useSession();
  const router = useRouter();
  const pathname = usePathname();
  const { isSaved, toggle, loading } = useWishlist();
  const [working, setWorking] = useState(false);

    sm: "w-8 h-8",
    md: "w-10 h-10",

    md: "w-5 h-5",

"use client";

import {
  createContext,
  useContext,
  useState,
  useEffect,
  useCallback,
} from "react";
import { useSession } from "next-auth/react";

type WishlistContextType = {
  savedIds: Set<number>;
  loading: boolean;
  toggle: (poiId: number) => Promise<void>;
  isSaved: (poiId: number) => boolean;
};

const WishlistContext = createContext<WishlistContextType | null>(null);

export function WishlistProvider({ children }: { children: React.ReactNode }) {
  const { status } = useSession();
  const [savedIds, setSavedIds] = useState<Set<number>>(new Set());
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    if (status !== "authenticated") {
      setSavedIds(new Set());
      setLoading(false);
      return;
    }

    setLoading(true);
    fetch("/api/wishlist/ids")
      .then((r) => r.json())
      .then((data) => {
        setSavedIds(new Set(data.ids ?? []));
      })
      .catch((err) => {
        console.error("Failed to load wishlist:", err);
      })
      .finally(() => setLoading(false));
  }, [status]);

  const toggle = useCallback(
    async (poiId: number) => {
      const wasSaved = savedIds.has(poiId);

      // Optimistic update
      setSavedIds((prev) => {
        const next = new Set(prev);
        if (wasSaved) {
          next.delete(poiId);
        } else {
          next.add(poiId);
        }
        return next;
      });

      try {
        if (wasSaved) {
          await fetch(`/api/wishlist/${poiId}`, { method: "DELETE" });
        } else {
          await fetch("/api/wishlist", {
            method: "POST",
            headers: { "Content-Type": "application/json" },
            body: JSON.stringify({ poiId }),
          });
        }
      } catch (err) {
        // Revert on failure
        console.error("Wishlist toggle failed:", err);
        setSavedIds((prev) => {
          const next = new Set(prev);
          if (wasSaved) {
            next.add(poiId);
          } else {
            next.delete(poiId);
          }
          return next;
        });
      }
    },
    [savedIds]
  );

  const isSaved = useCallback(
    (poiId: number) => savedIds.has(poiId),
    [savedIds]
  );

  return (
    <WishlistContext.Provider value={{ savedIds, loading, toggle, isSaved }}>
      {children}
    </WishlistContext.Provider>
  );
}

export function useWishlist() {
  const ctx = useContext(WishlistContext);
  if (!ctx) {
    throw new Error("useWishlist must be used within WishlistProvider");
  }
  return ctx;
}

import { prisma } from "@/lib/prisma";
import PermitSearch from "@/app/components/permits/PermitSearch";

const POPULAR_SLUGS = [
    "e-tims-registration",
    "sagarmatha-national-park",
    "khumbu-pasang-lhamu",
    "upper-mustang",
    "tourist-visa",
];

export default async function PermitsLayout({
    children,
}: {
    children: React.ReactNode;
}) {
    const popularPermits = await prisma.permit.findMany({
        where: {
            type: "permit",
            slug: { in: POPULAR_SLUGS },
        },
        include: {
            parent: {
                include: {
                    parent: {
                        select: { slug: true, name: true },
                    },
                },
            },
        },
    });


    const popularPermitsRaw = await prisma.permit.findMany({
        where: {
            type: "permit",
            slug: { in: POPULAR_SLUGS },
            parentId: { not: null },
            parent: {
                parentId: { not: null },
            },
        },
        include: {
            parent: {
                include: {
                    parent: {
                        select: { slug: true, name: true },
                    },
                },
            },
        },
    });

    // Sort by POPULAR_SLUGS order
    const orderedPopular = POPULAR_SLUGS.map((slug) =>
        popularPermitsRaw.find((p) => p.slug === slug)
    )
        .filter((p) => p && p.parent && p.parent.parent)
        .map((p) => p! as unknown as {
            id: number;
            name: string;
            slug: string;
            parent: {
                slug: string;
                name: string;
                parent: { slug: string; name: string };
            };
        });

    return (
        <>
            {/* Sticky search bar below site header */}
            <div className="sticky top-16 z-40 bg-[#f8f9fa]">
                <div className="max-w-3xl mx-auto px-4 py-3">
                    <PermitSearch popularPermits={orderedPopular} />
                </div>
            </div>

            {children}
        </>
    );
}

import { prisma } from "@/lib/prisma";

export type GeoRow = {
  geoId: number;
  parentId: number | null;
  name: string;
  type: string;
  slug: string;
};

/**
 * Walk up the parentId chain to build the breadcrumb.
 * Returns [Nepal, Koshi, Solukhumbu, Namche Bazaar]
 */
export async function buildBreadcrumb(geo: GeoRow): Promise<GeoRow[]> {
  const chain: GeoRow[] = [geo];
  let current = geo;

  while (current.parentId) {
    const parent = await prisma.geo.findUnique({
      where: { geoId: current.parentId },
      select: { geoId: true, parentId: true, name: true, type: true, slug: true },
    });
    if (!parent) break;
    chain.unshift(parent);
    current = parent;
  }

  return chain;
}

/**
 * Build a section URL: "/Hotels-g97740501-pokhara"
 */
export function sectionUrl(sectionKey: string, geo: GeoRow): string {
  return `/${sectionKey}-g${geo.geoId}-${geo.slug}`;
}

export function poiCategoryKey(category: string): string {
  return category.charAt(0).toUpperCase() + category.slice(1);
}

/**
 * Build a POI detail URL: "/Trek_Review-g97740501-d100002-annapurna-circuit-trek"
 */
export function poiUrl(
  poi: { poiId: number; slug: string; category: string },
  geo: { geoId: number }
): string {
  return `/${poiCategoryKey(poi.category)}_Review-g${geo.geoId}-d${poi.poiId}-${poi.slug}`;
}

import { prisma } from "@/lib/prisma";

export type PermitNode = {
  id: number;
  parentId: number | null;
  type: string;
  name: string;
  slug: string;
  description: string | null;
  displayOrder: number;
};

/**
 * Walk up the parent chain to build a breadcrumb.
 * Returns [root, ..., current]
 */
export async function buildPermitBreadcrumb(
  permit: PermitNode
): Promise<PermitNode[]> {
  const chain: PermitNode[] = [permit];
  let current = permit;

  while (current.parentId) {
    const parent = await prisma.permit.findUnique({
      where: { id: current.parentId },
      select: {
        id: true,
        parentId: true,
        type: true,
        name: true,
        slug: true,
        description: true,
        displayOrder: true,
      },
    });
    if (!parent) break;
    chain.unshift(parent);
    current = parent;
  }

  return chain;
}

/**
 * Build a permit URL from a breadcrumb chain.
 * Example: [category, subcategory, permit] → "/nepal-permits/trekking/protected-area/sagarmatha-national-park"
 */
export function getPermitUrl(chain: PermitNode[]): string {
  // Skip root-level category from URL? No — we include all levels.
  // If chain starts with category "trekking", the URL is /nepal-permits/trekking/...
  const segments = chain.map((node) => node.slug).join("/");
  return `/nepal-permits/${segments}`;
}

/**
 * Get the URL for a category only (Level 2)
 */
export function getCategoryUrl(category: PermitNode): string {
  return `/nepal-permits/${category.slug}`;
}

/**
 * Get the URL for a subcategory (Level 3)
 */
export function getSubcategoryUrl(
  category: PermitNode,
  subcategory: PermitNode
): string {
  return `/nepal-permits/${category.slug}/${subcategory.slug}`;
}

/**
 * Get the URL for a permit (Level 4)
 */
export function getPermitDetailUrl(
  category: PermitNode,
  subcategory: PermitNode,
  permit: PermitNode
): string {
  return `/nepal-permits/${category.slug}/${subcategory.slug}/${permit.slug}`;
}

async function upsertRoot(
  slug: string,
  data: { name: string; description: string; displayOrder: number }
) {
  const existing = await prisma.permit.findFirst({
    where: { parentId: null, slug },
  });
  if (existing) {
    return prisma.permit.update({
      where: { id: existing.id },
      data,
    });
  }
  return prisma.permit.create({
    data: { parentId: null, type: "category", slug, ...data },
  });
}

  for (const geo of geos) {
    await prisma.geo.upsert({
      where: { geoId: geo.geoId },
      update: {},
      create: geo,
    });
  }
  console.log(`✅ ${geos.length} geos inserted\n`);

  // Insert POIs
  console.log(`🎯 Inserting ${pois.length} POIs...`);
  for (const poi of pois) {
    await prisma.poi.upsert({
      where: { poiId: poi.poiId },
      update: {},
      create: poi,
    });
  }
  console.log(`✅ ${pois.length} POIs inserted\n`);

  console.log("🎉 Seeding complete!");
}

    process.exit(1);
  })
  .finally(async () => {
    await prisma.$disconnect();
  });
